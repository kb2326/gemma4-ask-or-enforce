## Review Focus

1. A finder that never finishes (time runs out in stage 1, or no final text): analysis must still produce a row (`finder_files_hit = False`, `first_write_kind = ''`), not crash. Test in Task 3.
2. A gold patch that only touches tests/docs gives no source gold files: such tasks are excluded from localization rates, not counted as hits. Test in Task 2.
3. Path spellings differ: the finder may write `rich/console.py`, `/workspace/rich/console.py` or `rich.console`; all three count as naming `rich/console.py`, a bare `console.py` does not. Test in Task 3.
4. Shell writes: `cat > rich/x.py <<EOF` is a source write, `echo hi > /tmp/t.py` is scratch, `cmd 2>&1` and `> /dev/null` are not writes. Test in Task 3.
5. A nudge restarts the pipeline, so one trace can contain two finder passes: per-stage time and calls sum both, and `finder_runs` counts them. Test in Task 3.

- Produces: `failure_split(rows: list[dict]) -> dict` with keys `no_source_edit`, `wrong_files`, `right_files` over unsolved tasks (a patch touching all gold files counts as right; partial overlap counts half to right and half to wrong, as in the original measurement).
- Produces: `analyze(trace_path, resolved, gold=None, finder='localizer')`; `main(results_dir, tasks_jsonl='data/agent/tasks.jsonl')`.

Definitions (from the spec, §2 and §4):
- A **write** is a `write_file`/`edit_file` call, or a `run_command` whose command writes a file via `>`, `>>`, `tee`, or `cat > ... <<`. Targets `/dev/null` and fd redirects (`2>&1`, `>&2`) are not writes. A write is **scratch** if its path starts with `/tmp`, else **source**. `first_write_kind` is the kind of the first write in the trace.
- **Stage** of a step = `step['extra']['author']`; finder steps are those authored by the `finder` agent name. `finder_runs` = number of maximal consecutive runs of finder-authored agent steps. For single-agent arms these are 0.
- **Nudges** = steps with `source == 'system'` and `extra.event_type == 'continuation_nudge'`.
- **compacted** = some agent step's `prompt_tokens` is below 70% of the maximum seen before it (ADK compaction shrinks the prompt). Replaces the `'previous agent'` text check.
- **finder_files_hit** = every gold source file is named in the finder's last text message (a finder step with no tool calls), matching `path`, `/workspace/path` or the dotted module (`a/b.py` → `a.b`); a bare basename does not count.
- **gold_files_edited** = the task's saved patch (`<results>/patches/<task>.patch`) touches every gold source file.
